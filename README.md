# 家計簿

財布と2つの口座を分けて管理できる、ローカル保存型の家計簿アプリです。

## 使い方

`index.html` をブラウザで開くと使えます。入力した内容はブラウザの `localStorage` に保存されます。

スマホでアプリのように使う場合は、GitHub PagesなどのHTTPSで公開されたURLをスマホのブラウザで開き、ホーム画面に追加してください。データは端末ごとのブラウザに保存されるため、端末間では共有されません。

総資産ページのデータ管理から、JSONファイルでのエクスポート・インポートができます。GitHub tokenを入力すると、このリポジトリ内の `data/household-data.json` に保存・読み込みできます。

公開リポジトリに保存した家計データは第三者から閲覧される可能性があります。実データをGitHubに保存する場合は、リポジトリをprivateにすることを推奨します。

## 主な機能

- 財布の残金表示
- 財布の入出金入力
- 2つの口座管理
- 固定収入・固定支出の自動入力
- 口座間振込
- 口座から財布への入金
- 収入・支出の円グラフ表示
- スマホ幅対応
- ホーム画面追加に対応するPWA設定
- JSONエクスポート・インポート
- GitHubリポジトリ内データ保存
