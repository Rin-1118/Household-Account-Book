# 家計簿

財布と2つの口座を分けて管理できる、ローカル保存型の家計簿アプリです。

## 使い方

`index.html` をブラウザで開くと使えます。入力した内容はブラウザの `localStorage` に保存されます。

スマホでアプリのように使う場合は、GitHub PagesなどのHTTPSで公開されたURLをスマホのブラウザで開き、ホーム画面に追加してください。データは端末ごとのブラウザに保存されるため、端末間では共有されません。

## スマホで開く・更新する場合の注意

GitHub Pagesで公開した直後は、ページ側のキャッシュにより数分ほど古い画面が表示されることがあります。変更が見えない場合は、スマホのブラウザでページを再読み込みし、それでも変わらない場合は一度タブを閉じてから開き直してください。

ホーム画面に追加したPWAは、通常のWebページより更新が反映されるタイミングが遅れる場合があります。新しい表示やボタンが出ない場合は、ホーム画面のアプリを完全に閉じてから再度開いてください。まだ古い画面が残る場合は、ブラウザ側でGitHub PagesのURLを開き直してから、必要に応じてホーム画面のアイコンを作り直してください。

オフラインでも開けるように `sw.js` で主要ファイルをキャッシュしています。そのため、公開後すぐに確認するときは「GitHub Pagesの反映待ち」と「PWAのキャッシュ更新待ち」の両方を疑ってください。

総資産ページのデータ管理から、JSONファイルでのエクスポート・インポートができます。GitHub tokenを入力すると、このリポジトリ内の `data/household-data.json` に保存・読み込みできます。

公開リポジトリに保存した家計データは第三者から閲覧される可能性があります。実データをGitHubに保存する場合は、リポジトリをprivateにすることを推奨します。

JSONを書き出したファイルは、iCloud Drive、Google Drive、Dropbox、OneDriveなどのクラウドにも手動で保存できます。アプリから直接クラウドへ保存する場合は、各サービスのAPI認証を別途実装する必要があります。

## 主な機能

- 財布の残金表示
- 財布の入出金入力
- `１ヶ月分（メイン）`と`貯金`の2つの口座管理
- 固定収入・固定支出の自動入力
- 固定収入・固定支出の前倒し入力
- 指定日到達後の固定収支残高反映
- 月ごとの記録リセット
- 口座間振込
- `１ヶ月分（メイン）`の出金を財布へ自動入金
- 収入・支出の円グラフ表示
- スマホ幅対応
- ホーム画面追加に対応するPWA設定
- JSONエクスポート・インポート
- GitHubリポジトリ内データ保存
